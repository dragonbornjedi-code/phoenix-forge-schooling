# Constitution — Phoenix Forge Schooling

## Identity

- **App ID:** `phoenixforge_schooling`
- **Package:** `com.phoenixforge.schooling`
- **Repo:** `phoenix-forge-schooling`
- **Brand:** PhoenixForge (one word for runtime); `phoenix-forge-*` for repos

## Product law

1. **One APK.** Steward and child are roles, not separate applications.
2. **Offline-first.** Core learning loops must work without internet.
3. **Child safety.** PROTECTED scope never exposed on the child face; signature IPC only.
4. **Kit sovereignty.** Build through phoenixforge-kit conventions; pull theme, data, widget as composite builds.
5. **Classroom is archive.** Requirements and code port from `phoenix-forge-classroom`; new work lives here.
6. **Evidence over claims.** No PASS without VERIFIED/TESTED tags and commands.
7. **Cline Essence.** Resilience first; black-swan hunting mandatory on mesh/sync/backup.

## Non-negotiables

- No unauthenticated LAN data planes
- No cleartext child PII on public storage
- No `protectionLevel="normal"` for child data permissions
- Frozen Godot file contracts unless World is updated in lockstep
